# Change Log

This is change log for [ess-smart-web-app](https://github.com/esafesys-eng/ess-smart-web-web/) project.

## 2.0.13
Released on Apr 7, 2026

### Changed
* when you click "Back to list" button, the form will have the current status.
* disabled image uploads in the rich text editor and fixed its light appearance in dark theme.

## 2.0.12

Released on Feb 19, 2026

### Added
* Added a `Reload` icon button in the list footer (next to entries) with loading state and click guard.

### Fixed
* add title for radio button
* Fixed list footer state after empty search results (`0 entries` + reload remain visible, stale pagination is hidden).

## 2.0.11

Released on Jan 28, 2026

### Fixed
* The file request for the checklist has been fixed.
* I fixed the background in the signature field for the dark theme.
* fixed required checkbox

### Added
* Opening the CA form now validates only the main form (subform checks are skipped).

## 2.0.10

Released on Oct 01, 2025

### Added
* Added breadcrumb output to subform
* Added the ability to return to the selected tab when using a subform
* A new version of `Voice Inspection` has been implemented, which allows you to pronounce text using the `Web Speech API` and analyze text at the browser level, as well as interface improvements.
* The ability to upload files has been added to the checklist.
* Improved tab performance, including on mobile devices.
* When you click Finish, the SubForm requires you to fill in the required fields.
