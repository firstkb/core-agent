# Commit Message Standard

Use Conventional Commits:

`<type>(<scope>): <subject>`

## Allowed types

- `feat`
- `fix`
- `docs`
- `refactor`
- `test`
- `chore`
- `perf`
- `style`

## Subject rules

1. Lowercase and imperative.
2. No trailing period.
3. Keep concise.

## Scope guidance

- Prefer repository vocabulary: `agents`, `commands`, `runtime`, `skills`, `docs`, `standards`.
- Omit scope when it does not add clarity.
