# Archived Runs

Status: active

This folder holds closed or superseded run artifacts that should no longer stay hot under `platform/docs/ai/runs/`.

Archive here when:
- the run is `closed` or `superseded`
- it is no longer part of active work
- keeping it in `runs/` would create noise or misleading default reads

Archived runs are historical execution artifacts.
They are useful for audit and restart context, but they are not canonical memory.
