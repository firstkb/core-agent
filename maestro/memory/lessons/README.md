# Lessons

Status: local episodic memory index

This folder is for reusable lessons that span multiple modules.
Most lessons should live close to their module in `modules/**/lessons.md`.

Use this folder only for cross-cutting lessons that apply broadly.

## Rules

- Keep each lesson short.
- Name the trigger condition.
- Name where it applies.
- Do not paste run history.
- Do not store chat transcripts.

## Current Cross-Cutting Lessons

- Do not let implementation-specific docs become canonical runtime truth without updating the owner surface.
- Do not read large docs or vendor folders before checking `memory-index.yaml` and module packs.
- Do not infer tenant or auth behavior from frontend convenience state; verify backend owner surfaces.
- Do not keep closed runs in hot retrieval.
