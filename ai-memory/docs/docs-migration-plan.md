## Action Values

- `keep`: keep active, with only minor cleanup.
- `move`: move to the target structure with content mostly intact.
- `compact`: extract durable facts into a smaller target doc.
- `merge`: combine with other docs into one target doc.
- `archive`: move to archive after durable facts are captured.
- `supersede`: replace with a newer target doc and mark the old doc superseded.
- `reference`: move or link as opt-in reference material.

## Migration Rules

- Do not move a source doc until its durable facts are captured in the target doc or module memory.
- Do not copy stale lifecycle language into target contracts.
- Keep active docs contract-first; move plans, prompts, audits, and donor material out of the hot path.
- Treat current apps as online web apps. PWA/offline and Flutter/mobile docs are proposals until explicitly activated.
- Reference code such as Metronic must not live in active FE/BE docs.
- Cite donor/legacy material through `reference-pack:*` aliases before opening raw packs.
