# Maestro vNext Examples

These examples are fixtures for humans and agents. They are not active work.
Use them to understand the smallest useful artifact shape for each tier.

- `t1-task/` - persisted lightweight task with `work.md` and closeout.
- `t2-staged/` - implementation plus verification handoff.
- `t3-multi-step/` - continuity-focused multi-step work with `work.md`,
  aggregate evidence, one JSON evidence item, and a minimal orchestration plan.
- `t4-gated/` - high-risk gated work with approval record.
